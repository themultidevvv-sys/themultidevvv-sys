## 🎴 Calling Card · About me

I am a junior developer focused on program logic and how systems operate. My work centers on designing logic, defining system behavior, and building the core ideas of each project. My profile leans toward the backend—the layer where application rules, data, and behaviors are defined.
 
Since 2022, I have independently developed my own projects. Along this path, I have worked with C# and .NET, Node.js, React, and relational databases such as SQL Server, PostgreSQL, and MySQL.
 
My professional interest lies in accounting and financial management software for cooperatives, financial institutions, and banks—environments where precision, access control, and information traceability are essential. Because of this, my projects focus closely on transaction logic, user roles, and movement history.
 
I complement my profile with systems and security knowledge: I am comfortable using the terminal at a basic-to-intermediate level and hold an initial foundation in ethical hacking, ranging from man-in-the-middle attacks to network scanning. I have participated in a CTF on the CTF Magic platform as practical training for these skills.
 
I am self-taught, detail-oriented, and eager to keep growing within professional environments.

## 🗼 Tartarus · Projects

### Floor 1 · Banking System

![C#](https://img.shields.io/badge/C%23-0B0D2A?style=flat-square&logo=csharp&logoColor=E3242B)
![SQL Server](https://img.shields.io/badge/SQL_Server-1B1B4D?style=flat-square&logo=microsoftsqlserver&logoColor=E3242B)
![Status](https://img.shields.io/badge/Status-Completed-E3242B?style=flat-square)

 
**Overview.** An administrative system featuring account management and role definition, built in C# with a remote connection to Microsoft SQL Server. This is an independent personal project started in 2023.
 
**Features**
 
- Account management: Users can access their bank accounts, create new accounts, or remove existing ones.
- Operations: Deposits, withdrawals, and transfers.
- Movement history tracking.
- User role definitions with varying access levels.

**Technical Aspects**
 
- C# application remotely connected to a Microsoft SQL Server database.
- CRUD operations implemented across system entities.
- Transaction logic governing deposits, withdrawals, and transfers.

**Competencies Applied:** Relational data modeling, object-oriented programming, business logic, and role-based access control.
